Status and category pill — uppercase mono on a tinted ghost fill in a semantic tone.

```jsx
<Badge tone="success" dot>passed</Badge>
<Badge tone="info" dot>running</Badge>
<Badge tone="accent" square>reasoning</Badge>
<Badge tone="warm">uncensored</Badge>
```

Tones: `neutral · accent · success · warn · danger · info · warm`. `dot` adds a leading status dot; `square` swaps pill→chip radius; `solid` fills (accent/success).
