Labeled 0-100 bar for "which model is better for this?" readouts — role-fit, benchmark scores, capacity. Appears on EntityCards, peek panels, and compare columns.

```jsx
<FitBar label="coding" value={90} hint="best on fleet" />
<FitBar label="reasoning" value={40} />
<FitBar label="mem" value={72} color="var(--warn)" showValue={false} />
```
