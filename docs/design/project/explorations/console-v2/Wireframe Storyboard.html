Enclave · console v2 exploration · wireframe pass · for review

The chat-led console

The v1 kit made the Composer the home screen — canvas first, chat docked underneath. This pass inverts it: the conversation is the home, and everything else is a graduation of it. A chat grows structure, converts into a workflow, and the canvas (kept, with its palette) becomes the place you refine what the chat already proved.

What this corrects from v1
  • Home was the canvas — intimidating empty state, no on-ramp.
  • Chat was a dock — an accessory, not the way in.
  • No path from "talking to a model" to "owning a workflow".
  • Creating models / agents / skills / plugins each felt different.
My recommendation

Direction C — "one thread, two modes." Chat home for seeding and shaping; an explicit Convert scaffolds a DAG and opens the existing Composer as a takeover, with the same thread docked as the test surface. Drill-downs use one peek → push card; every wizard verifies the same way — you talk to the thing.
